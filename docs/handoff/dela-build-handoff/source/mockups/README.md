# DELA Workflow Mockups: 10 Screens

Illustrative UX concepts based on `DELA_Build_Handoff(1).md` and the Lawfecta design direction. Every PNG is a separate desktop screen, with a non-product design-sequence label at top and bottom. The sequence **does not** impose a required in-product wizard; conversation remains the starting point.

01. Playbook-Aware Conversation
02. My Playbooks Library
03. Delegation Opportunities
04. Partial Delegation & Dependencies
05. DELA Instructions & Firm Context
06. Create a Gig from DELA
07. Playbook Changes & Version Approval
08. Invitation & Sharing Review
09. Recipient Review & Acceptance
10. Decisions, Blockers & Work Progress

Example people, policies, playbooks, approval states and work items are demonstrative only; no backend integration or permission model is represented as already implemented. Later-phase concepts (invitations, execution status, approval events) require validation before shipping.
